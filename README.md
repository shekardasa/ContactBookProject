Java Contact Book

Project Overview

A simple console-based Contact Book application developed using Java. It allows users to manage contact information through an interactive menu.

Features

- Add new contacts
- View all saved contacts
- Search contacts by name
- Delete contacts
- Manage contact details

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Eclipse IDE

Project Structure

ContactBookProject/
├── Contact.java
├── ContactBook.java
├── Main.java
├── package-info.java
└── README.md

Concepts Implemented

- Classes and Objects
- Encapsulation
- Constructors and Methods
- ArrayList Collection
- User Input Handling
- Conditional Statements and Loops

How to Run

1. Clone or download this repository.
2. Import the project into Eclipse IDE.
3. Ensure Java is configured.
4. Open "Main.java".
5. Run the application as a Java Application.
